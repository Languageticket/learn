# LanguageTicket Learn

The standalone public blog for `learn.languageticket.com`.

## What to edit

- `public/index.html` is the blog home page.
- Each article is a folder in `public/` with its own `index.html`.
- `public/logo.png` and `public/favicon.png` are the shared brand assets.
- `public/sitemap.xml` lists the pages for search engines.

## Publishing

This is a static site. Cloudflare Pages should publish the `public` folder with no build command.

The marketing site is separate. Its URLs are linked in the blog navigation, while blog links stay on `learn.languageticket.com`.
